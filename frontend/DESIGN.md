# TwoPills 디자인 규칙

이 파일이 `frontend/index.html`의 시각 규칙의 원천이다. 화면과 이 파일이 다르면 이 파일을 먼저 고치고 화면을 맞춘다.
흐름·문구의 원천은 `docs/scenarios.yaml`(S1~S8)과 `docs/problem.yaml`(features F1~F9)이다. 이 파일은 "어떻게 보이는가"만 정한다.

## Overview

(0단계 초안. 01단계 `/frontend-design`에서 확정한다.)

화이트 톤 의료·헬스케어 랜딩. 흰 바탕에 아주 옅은 회색 면으로 구역을 나누고, 채도 높은 색은 자두색 하나만 쓴다.
헤드라인은 Hahmlet 세리프를 가는 300과 굵은 700으로 섞어 쓰고, 굵은 쪽만 자두색로 칠한다.
히어로 오른쪽에 CSS로 그린 알약·캡슐이 떠다니는 패널을 두는 것이 이 화면의 유일한 대담한 요소다. 나머지는 조용하다.
판정 결과는 색으로만 구분하지 않는다. 아이콘·글자·색 셋이 항상 같이 간다. "안전"이라는 단정과 초록색은 쓰지 않는다.

## 금지

- 보라·그라데이션 CTA, 크림 바탕, 이모지 섹션 마커
- Inter / Roboto / Space Grotesk
- 자두색 외의 채도 높은 색
- 판정 결과에 초록색, "안전"·"문제없어요"·"먹어도 돼요" 같은 단정
- 스크롤 트리거로 콘텐츠를 숨겨 두는 것(첫 프레임에 전부 보여야 함), 무한 반복으로 주의 끌기, 300ms 넘는 지연
- `prefers-reduced-motion: reduce`에서 움직이는 것

> 2026-10-30 사용자 요청: 메인 색은 파랑·초록 계열을 피하고 연보라 배경과 어울리는 짙은 자두색(aubergine)으로 바꿨다. 배경은 보라 그라데이션(양옆 알약 이미지, 가운데는 밝게)이고, 이 문서 위쪽 "금지" 중 보라·그라데이션 항목은 배경에 한해 해제한다.

## 라운드

`--r-1: 14px` 입력·작은 카드 / `--r-2: 22px` 카드 / `--r-3: 28px` 큰 패널·히어로 패널 / `--r-pill: 9999px` 버튼·칩·배지. 이 넷 외에는 쓰지 않는다.

## 간격

8px 배수만. 섹션 세로 64px, 카드 안쪽 24px, 그리드 간격 16px, 폼 요소 사이 16px, 본문 문단 사이 8px.
본문 폭은 65자(한글 기준 약 640px) 안.

## 타이포

전부 **KofihJongwook**(굵기 300 / 700 두 단계)으로 통일한다. 400·500은 300으로 렌더링되므로 강조는 반드시 700을 쓴다. 서브셋에 없는 글자는 Malgun Gothic → Apple SD Gothic Neo → sans-serif로 대체된다.

| 역할 | 폰트 | 굵기 |
| --- | --- | --- |
| 헤드라인 | KofihJongwook | 300 + 강조 700(자두색) |
| 본문·UI·숫자 | KofihJongwook | 300(본문) / 700(버튼·라벨·숫자) |

크기 스케일(px): 11 / 13.5 / 15 / 18 / 28 / 40 / 66. 본문은 15 이상(모바일 앱 화면 본문 16px 규칙은 `--fs-3: 15px`를 모바일에서 16px로 올려 지킨다).
행간: 헤드라인 1.15, 본문 1.6.

## 컴포넌트

- 버튼: `.btn` 기본(흰 바탕 테두리) / `.btn-primary`(자두색) / `.btn-black`(검정) / `.btn-ghost`(투명). 높이 48px(터치 44px 이상), 라운드 `--r-pill`. 화면마다 주 행동 버튼은 하나.
- 칩 `.chip`: 설문 선택, 히어로 떠다니는 라벨. 라운드 pill.
- 배지 `.badge`: 종류(일반약/처방약/영양제), 판정 단계. 색은 상태 토큰.
- 경고 창 `.modal`: 맨 위 단계 문구(18px 700) → 대처 방법(28px Hahmlet) → 성분 짝 → 원문 인용(`blockquote`) → 출처 → 약사에게 물을 질문 → 상담 안내 → 버튼 '자세히'·'그래도 추가'·'취소'.
- 토스트 `.toast`: 아래 가운데, 3초.
- 빈 상태 `.empty`: 아이콘 없이 한 문장 + 다음 행동 버튼.
- 포커스 링: `outline: 3px solid var(--cobalt); outline-offset: 2px` 모든 상호작용 요소.

## 반응형

데스크톱 1200px 기준. 760px 아래에서 1열, 상단 탭이 아래 고정 탭(홈·복용 목록·분석하기)으로 바뀐다. 가로 스크롤 없음.

## 모션

(04·05단계에서 토큰 확정) 초안: `--ease: cubic-bezier(.2,.7,.2,1)`, `--dur-1: 120ms`, `--dur-2: 200ms`, `--dur-3: 300ms`, `--dur-4: 600ms`.
`transform`·`opacity`만 움직인다. `prefers-reduced-motion: reduce`면 전부 끈다.
