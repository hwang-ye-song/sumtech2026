# 일반의약품 데이터 (자주 쓰는 약 58개)

타이레놀·게보린·판피린 같은 자주 쓰는 일반의약품의 공식 소비자용 정보와, 그 문구에서 뽑은 **병용 주의 규칙**(무엇과 같이 먹으면 안 되는지)입니다.

## 출처

- 식품의약품안전처 의약품안전나라 **e약은요**(일반 소비자용 의약품 개요 정보). 품목마다 `source_url`에 원문 주소가 있습니다.
- e약은요 안내문 그대로: 의약품에 관한 모든 내용을 담고 있지 않으며, 본 정보는 법적 효력을 가지는 것이 아닙니다.
- 2026-10-29에 품목별로 조회했습니다. 사이트 전체를 수집하지 않았습니다(사이트가 자동 수집을 막고 있음).

## 파일

| 파일 | 내용 |
| --- | --- |
| `schema.sql` | 테이블 정의 (PostgreSQL·SQLite 공통) |
| `seed.sql` | `schema.sql` 다음에 실행하면 아래 데이터가 모두 들어감 |
| `otc_core.json` | 약 58개 전체(원문 + 성분 + 규칙)를 한 파일에 담은 것 |
| `drug.csv` | 약 58개: 제품명, 업체, 분류, 효능, 사용법, 경고, 주의사항, 상호작용, 이상반응, 보관법, 원문 주소 |
| `drug_ingredient.csv` | 약별 주성분 240행. 영양제에도 흔한 성분이면 `nutrient`에 통일한 이름(비타민B1, 칼슘, 마그네슘 등, 106행) |
| `drug_caution_rule.csv` | 병용 주의 규칙 589개 |

SQLite로 확인하는 방법:

```bash
sqlite3 drugs.db < data/drugs/schema.sql && sqlite3 drugs.db < data/drugs/seed.sql
```

## 병용 주의 규칙 (`drug_caution_rule`)

| 열 | 뜻 |
| --- | --- |
| `counterpart` | 같이 먹으면 주의할 대상, 통일한 이름 (알코올, 칼슘, 와파린, 탄닌 함유 차 …) |
| `counterpart_raw` | 원문 표현 그대로 |
| `counterpart_type` | `drug` 490 · `alcohol` 49 · `food_drink` 26 · `supplement_nutrient` 22 · `caffeine` 1 · `other` 1 |
| `relation` | `avoid`(먹지 말 것) 233 · `consult`(의사·약사와 상의) 320 · `duplicate_ingredient`(같은 성분 중복) 20 · `separate_timing`(시간 간격) 9 · `caution` 7 |
| `effect` | 원문이 결과를 직접 말할 때만 (예: 간손상, 우유 알칼리 증후군). 없으면 빈칸 |
| `quote` | 근거 원문 문장 그대로 |
| `field` | 근거가 있던 항목 (interactions / warning / precautions / usage) |

만든 방법: AI가 품목별 원문에서 규칙을 뽑고, 다른 AI가 규칙마다 원문과 대조해 고치거나 지우고 빠진 것을 더했습니다. 마지막으로 스크립트가 모든 `quote`가 원문에 글자 그대로 있는지 확인했습니다(589개 모두 통과, 버린 규칙 0개). 환자의 질병·나이·임신 같은 상태는 규칙에 넣지 않았습니다.

영양제와 관련된 예:

- 비타민B군 제제(삐콤씨·임팩타민·벤포벨·비맥스·마그비 등) × 칼슘염·인산염: 함께 복용하지 마십시오
- 철분제(볼그레·헤모큐) × 녹차·홍차 등 탄닌 함유 차, 우유·유제품: 복용 전후 피하십시오
- 마그밀(수산화마그네슘) × 칼슘제제·다량의 우유: 우유 알칼리 증후군 → 상의
- 알레그라 × 자몽·오렌지·사과주스: 약효 감소 → 물과 함께 복용 권장
- 개비스콘·알마겔(제산제) × 철염: 상의

## 한계

- **원문에 없는 조합은 이 데이터로 "안전하다"고 말할 수 없습니다.** 규칙이 없다는 것은 e약은요 문구에 적혀 있지 않다는 뜻일 뿐입니다.
- 소화제 6종(베아제정, 훼스탈골드정, 닥터베아제정, 까스활명수큐액, 속청큐액, 동성정로환에프정)은 원문에 병용 주의 문구가 없어 규칙이 없습니다.
- 주성분 **함량(mg)은 없습니다.** e약은요 검색 목록의 주성분 이름만 있습니다.
- 코대원·박카스·인사돌은 e약은요에 없어 빠졌습니다. 가스터와 로페시콜 대신 같은 성분의 경동파니틴정(파모티딘)과 다이어스탑캡슐(로페라미드)을 넣었습니다.
- 검색어와 실제 품목이 다른 경우: 스멕타 → 다이톱현탁액(같은 성분), 훼로바 → 훼로바맘스케어정(종합비타민형), 니코레트 → 니코레트인비지패취(붙이는 제형).

## 전체 품목(약 4,700개)과 성분 함량이 필요하면

`scripts/fetch_easy_drug_api.py`가 공공데이터포털 e약은요 OpenAPI로 전체 품목을 받습니다. data.go.kr에서 "식품의약품안전처_의약품개요정보(e약은요)" 활용신청 후 받은 인증키(Decoding)를 `.env`의 `DATA_GO_KR_SERVICE_KEY`에 넣고 실행하세요. 성분별 함량은 같은 키로 "의약품 제품 허가정보" API의 주성분 상세정보를 쓰면 받을 수 있습니다(스크립트는 아직 없음).
